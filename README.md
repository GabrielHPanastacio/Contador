# Contador Interativo 🔢

Uma aplicação web simples e funcional desenvolvida para gerir um contador dinâmico com operações de incremento, decremento e reinicialização.

## 🎯 Objetivo do Projeto

Praticar conceitos essenciais de JavaScript, com foco especial na seleção de elementos do DOM, gestão de variáveis de estado, escuta de eventos de clique e atualização de dados na interface em tempo real.

## 🛠 Tecnologias e Conceitos Aplicados

- **HTML5:** Estruturação semântica da interface com elementos de exibição (`<span>`) e botões de controlo.
- **CSS3:** Estilização moderna com paleta de cores escura, alinhamento absoluto centrado por Flexbox e tipografia em destaque.
- **JavaScript (ES6):**
  - Seleção de nós do DOM com `document.querySelector`.
  - Criação e manipulação de variáveis de estado com `let`.
  - Registo de eventos dinâmicos com `addEventListener('click', ...)`.
  - Modificação de propriedades de texto com `.textContent`.
